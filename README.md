# Fogo Bonito · Brazilian Steakhouse

Landing page premium para **Fogo Bonito**, steakhouse brasileño en San Salvador. Estética oscura y cinematográfica, con detalles sutiles de la bandera de Brasil (verde y amarillo), fuego animado y módulos dinámicos. Construida con HTML, CSS y JavaScript vanilla (sin dependencias ni build).

## Módulos dinámicos

- Partículas de brasa animadas en `<canvas>` (respeta `prefers-reduced-motion`).
- Rotador de palabra en el hero ("Pasión por la parrilla / brasa / fogo / churrasco").
- Carrusel automático de cortes con barra de progreso, pausa al pasar el cursor y navegación por teclado.
- Menú por categorías con transición animada.
- Contadores animados y reveal on-scroll.
- Ticker/marquee infinito.
